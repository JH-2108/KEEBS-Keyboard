# Custom 80% Mechanical Keyboard
A custom-designed 80% mechanical keyboard featuring an integrated side display, rotary encoder, hot-swappable mechanical switches, and a custom-designed PCB. 

The project combines electronics, embedded programming, PCB designing and development, and mechanical CAD to create a fully functional and customizable keyboard. 

# Project overview
The keyboard uses a traditional tenkeyless (TKL) layout, retaining the function row, navigation cluster, and arrow keys while removing the dedicate number pad. 

An addition control module will be integrated into the right side of the keyboard, featuring a small display and rotary encoder. 

# Key Features
- 80% TKL keyboard layout
- custom designed PCB using kiCAD
- RP2040 microcontroller
- Soldered on mechanical switches
- integrated OLED display
- rotary encoder with push-button functionality
- USB-C connectivity
- custom keyboard firmware
- custom 3d printed enclosure

# Hardware 
| Component | Purpose |
|---|---|
|RP2040 microcontroller | Main microcontroller | 
| mechanical switches | keyboard input | 
| soldered on MX-cherry key switches | keyboard keys | 
| OLED display | Side mounted information display |
| EC11 rotary encoder | volume and menu control | 
| USB-C connector | Power and date connectivity | 
| Passive components | power management and signal conditioning | 
| custom PCB design | Main electronics platform | 
| 3D printed enclosure | Keyboard housing | 

# Display functions 
The integrated display will provide  customizable interface with features such as: 
- Current time and date
- Volume level indicator 
- Keyboard layer information
- media information
- custom animations
- keyboard configuration menus

# Rotary encoder functions 
The rotary encoder will be positioned beside the display. 

Planned functionality: 
- Rotate to adjust system volume
- press to mute or unmute
- navigate display menus
- Adjust keyboard settings

# Firmware 
The keyboard firmware will be developed using QMK firmware, with custom functionality for the display and rotary encoder. 

Planned software features:
- Keyboard matrix scanning
- custom key mapping
- USB HID communication
- Rotary encoder configuration
- Display interface and animations
